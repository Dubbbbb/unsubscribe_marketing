## Текущее положение

- По словам владельца, шаблон сайта подготовлен, платежка для РФ найдена. Домен и развёртывание впереди; название платежки и финальный бренд не зафиксированы.
- Основной следующий тест: разные небольшие авторы с женской аудиторией; после звонка приоритет исследования — авторские видео с оплатой за просмотры.
- Изначально обсуждали 5–6 блогеров по 2–5 тыс. ₽ за пост. Это ориентир, а не утверждённый бюджет новой модели.
- Посевы не исключаем; поиск запускаем второстепенно после готовности сайта.
- Сейчас нужно собрать условия креаторов за неделю общения, сравнить предложения и определить экономику теста.
- Нет зафиксированных запусков, расходов, договорённостей с авторами или результатов продаж.

## Как читать данные

Документация восстановлена из предоставленной переписки и заметок владельца о звонке. При сохранении повторная проверка прайсов и рекламных кабинетов не проводилась. Числа из предыдущего исследования — исторический срез, не обещание текущих условий.

Различаем: **решение владельца**, **предложение маркетолога**, **гипотеза**, **предварительный результат исследования**, **неизвестно**. Предложения ассистента не считать автоматически принятыми решениями.

## Как обновлять

- Новые условия автора заносить в реестр с датой и источником; старую цену сохранять как историю.
- У каждого теста хранить расходы, ссылки, результаты и выводы.
- Решения обновлять в контексте; гипотезы закрывать только по данным.
- Не записывать пароли, токены кабинетов, платёжные секреты и личные данные покупателей.
- Этот репозиторий — место для маркетинга данного проекта; не смешивать с market-discovery и другими проектами.
