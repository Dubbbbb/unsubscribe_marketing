## Что доработать

1. **Просмотры Reels — главный пробел.** 0 из 80 публикаций имеют views. Добавить извлечение доступных счётчиков из соответствующего представления страницы и проверить после авторизации. Не обещать, что вход сам решит проблему.
2. **Подозрительные лайки.** Ровно 3 у всех постов sofa_beauty, qd.dr, amina_black_afgano_ и у большинства постов нескольких других авторов. Возможное скрытие счётчиков/служебное значение — гипотеза, не установленная причина. Проверить исходные данные и отображение, учитывать флаг скрытия; возвращать null при отсутствии достоверного значения, не заменять любую тройку автоматически.
3. **Совместные публикации.** В alena.alexxandrova попал пост Dcym3b7jd8y с author=mashu_love и 6 179 лайками. Добавить is_collaboration/coauthors или явное предупреждение author_mismatch и раздельную статистику. Это может быть валидный collab, не обязательно ошибка извлечения.
4. **Фильтр типа публикаций.** Нужен режим reels_only. Сейчас лимит 5 расходуется и на карусели, для рекламного видео это недостаточная выборка.
5. **Закрепление и хронология.** is_pinned=null; chronological_completeness_verified=false. Не называть выборку гарантированно последними роликами.
6. **Авторизация.** В MCP доступны только crawl_page, inspect_creator, inspect_post. Нет инструмента открытия окна входа, проверки auth_status и выбора профиля. В доступных UI-поверхностях браузера Crawl4AI не обнаружено. Вход во встроенный браузер ChatGPT не означает вход в парсер. Добавить открываемый пользователем браузер/ссылку на экран и сохранение профиля; затем сравнить одни и те же URL до/после входа.
7. **Диагностика через MCP.** Возвращаются относительные пути diagnostics/...; нужен способ получить скриншот/фрагмент по ID, чтобы оценивать ошибки из чата.
8. **Очередь и таймаут.** При параллельных запросах длительность растёт примерно ступенчато; вероятна сериализация. beauty.mutim вернул partial с timeout после 87 секунд при бюджете 90, сохранив 5 постов. Разделить queue_seconds и fetch_seconds; рекомендовать размер пачки по фактической ёмкости.
9. **Проверка активности.** Для уверенной оценки нужны тексты некоторого числа комментариев и подтверждённые актуальные просмотры; автоматическая пометка «живые» по одному числу подписчиков недопустима.
